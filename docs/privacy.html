Privacy Policy for Streakly

Last updated: October 11, 2026
No data collected. No data shared. No exceptions.

Streakly is an offline habit-tracking app. This policy is short because the app genuinely does very little with your information: it doesn't collect, store on a server, transmit, or share any personal data, because it has no server at all.

What Streakly does not do

  • No account or sign-in of any kind
  • No analytics SDK, no advertising SDK, no crash-reporting SDK
  • No network requests to send your data anywhere
  • No sharing or selling of data to any third party, because none is ever collected

Where your data actually lives

All habit data you create — habit names, streaks, completion history, reminder settings — is stored only in this app's local storage on your own device, using Android's standard on-device database. Streakly never uploads it anywhere automatically.

Export and backup

Streakly includes an optional "Export my data" feature. If you use it, the app saves a file to a location you choose, using Android's standard system file picker. That file never passes through any server Streakly controls — it goes exactly where you tell your phone to put it, and only you decide what happens to it afterward.

Uninstalling the app

Uninstalling Streakly permanently deletes all of its local data from your device, unless you previously exported a backup yourself.

Changes to this policy

If this policy ever changes — for example, if a future version of the app adds an optional feature that does involve network access — this page will be updated first, with a new "Last updated" date above.
